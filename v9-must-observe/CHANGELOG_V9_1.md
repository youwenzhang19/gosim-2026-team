# v9.1 修改、实测与边界

日期：2026-10-07。基线为 v9-probe.zip，SHA256：87bcc90aa34b527f1f386a7b3a150a8105e07fb0d2c8d9d69a388d4f3f78fb94。原包未修改。

## 改了什么

运行代码只改 planner.py；scale_estimator.py、agent.py、operations.py、llm_client.py 和其余原 Python 模块逐字保留。planner.py 的 clean_e 也未改。另新增测试与本文、刷新 README、验证结果及清单。原 FAULT_REPORTING_TODO.md 保留。

1. 取消每个探针都全量扩池。先按原科学收益选靶；已有至少一个预测可用的方向干净、非饱和校准目标时不补搜。科学每光纤 gain 排序、零收益探针豁免、等待计时及原有失败扩池保留。
2. 校准不再依赖 active/value：完成科学任务的目标也能校准；科学候选池为空时，探针仍能进入独立搜索，不会过早返回。
3. 先同视场、再有限换视场。同视场最多为校准替换/增加两根光纤，其余保持科学收益选择。只有没有可用校准星才试新视场；换视场会改变整次科学目标，不能理解为全局最多改变两根光纤。
4. 不盲选最亮星。用参考好条件检查饱和余量，检查曝光开始/中间/结束时的方向与高度。实际反馈是否有限仍由原 scale estimator 判定，不能用预计可用宣称实际精确。
5. 分级限制新增 exact 模型数量：级别 0–4 为 192/128/96/64/48；校准 anchor 上限 8/6/4/3/2，每个最多四个中心光纤布局。额外几何扫描仍为 O(N)，不是恒定总耗时；上限不包含原科学失败扩池的成本。
6. 补搜选出校准方案后，仅在当前决策时刻通过 planner.record_action 保护它不被科学重排覆盖。下次 plan 清除保护。没有改 agent/API 或报修接口。

## 参数不是物理真值

- CALIBRATION_MAX_REACH=0.85 是搜索防饱和余量；max(1.0, measured_scale) 是选校准星的参考尺度，不会托高 scale 点估计。粗排参考 reach=0.5 是信号/饱和余量的启发式折中，不是日期或卡片名称硬编码。
- 一次曝光已有一个潜在有限目标即可避免扩搜；不存在必须凑四个样本才看见变化的门槛。有界搜索不保证覆盖所有可行目标。
- 全饱和、无干净方向、几何约束或预算用完时，保留原合法探针/返回等待，不伪造校准成功。未知方向性效应和参考尺度失准仍可能导致估计误差。
- 未调整自适应探针频率：本次混合八夜有 8 次 nightly + 82 次 adaptive。未来可另做信息收益/曝光成本试验，不为少数本地卡继续硬调参数。

## 测试与使用

原有 13 项 + 新增 14 项，共 27 项通过。新增覆盖等待回调、零收益探针、空截断池、污染方向正收益、已完成校准星、无干净目标、全封锁、各级预算、全饱和与同视场光纤保留、提交保护及最短曝光。

Python 3.12，工作目录为本包根目录（工具包路径需自行设置）：

    $env:OBSERVER_KIT_ROOT='C:/your/path/gosim-observer-examples'
    $env:PYTHONDONTWRITEBYTECODE='1'
    python -m unittest discover -s tests -p 'test_*.py' -v
    python tests/run_offline_comparison.py --kit TOOLKIT_PATH --card L1_CARD_PATH --out NEW_EMPTY_OUTPUT_DIR

基线对照可加 --agent-root C:/your/path/v9-probe.zip --version v9-original。输出目录必须不存在。测试需要外部公开 runner 和完整 L1 卡；本包不含卡片真值。validation/ 摘要对应最终 planner 哈希；MANIFEST.json 记录除清单本身之外的随包文件哈希。

ZIP 根目录直接含 observer.project.json 和 agent.py，运行配置与 v9 相同。建议以候选版运行平台完整卡，比较总分、REQUIRED、整夜等待与 probe/scale 日志。原 v9 保留用于回退。
